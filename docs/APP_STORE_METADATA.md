# Store Metadata

## App Name

Core-Monitor

## Subtitle

Mac system monitor with weather

## What's New in 3.0

- New design: a sidebar with a page for each part of your Mac, plus three minutes of live charts.
- CPU usage is now split correctly between performance and efficiency cores.
- Battery health and time remaining on Mac laptops.
- Choose what the menu bar shows, and how often Core-Monitor updates.
- Weather is now off until you turn it on in Settings, and it uses only Apple Weather.

## Description

Core-Monitor gives you a readable live view of CPU activity, per-core load, memory pressure, network throughput, storage usage, battery status, the system thermal state, and optional local weather.

It stays read-only. It does not install helper tools, control fans, change system behavior, or require an account.

## Feature List

- Watch overall CPU activity and per-core load at a glance.
- Check memory use, compression, and available headroom.
- Track current download and upload throughput.
- View startup disk usage, uptime, and load averages.
- Monitor battery charge and charging state on supported Macs.
- Follow system thermal state and warning level.
- Turn on local weather from Apple Weather if you want it.
- Keep a live summary in the menu bar.

## Notes

- Weather is off by default and requires location approval.
- The thermal card uses system thermal signals because exact CPU temperature is not exposed through the system frameworks used by this edition.
