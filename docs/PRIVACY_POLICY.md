# Privacy Policy

## Summary

Core Monitor does not require an account and does not collect analytics, tracking data, or personal profiles.

## Data Collection

The app operates locally on the Mac.

- No account creation
- No analytics SDKs
- No advertising SDKs
- No tracking
- No telemetry pipeline
- No remote profile building

## Data Handling

The app reads limited device status locally to show:

- CPU activity and per-core load
- memory usage
- battery and power-source status
- thermal state and warning level
- network throughput
- startup disk usage
- uptime and load averages
- local weather when the user grants location access

This information stays on the device and is used only to render the interface.

## Permissions

The app requests location only when the user enables weather.

The app does not request camera, microphone, contacts, photos, accessibility, input monitoring, automation, or full disk access.

## Network Use

The app uses the network only for WeatherKit data and the required Apple Weather attribution assets when the weather feature is active.
